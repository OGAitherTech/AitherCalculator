# Aither Calculator

A fast, mobile-first calculator by Aither.

## Version

**2.0.0**

## What's new in 2.0

- Memory controls: MC, MR, M+, and M−
- DEG/RAD angle switching for trigonometry
- x³ and exponent (xʸ) scientific operations
- Euler's number (e)
- Parenthesis input
- Sound effects option
- Copy current result from Settings
- Expanded calculation history with timestamps
- History increased to 50 calculations
- Improved responsive layout for small iPhones and desktop screens
- Refreshed settings panel and mobile-safe UI
- Force Update remains available in Settings

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Percentage and positive/negative controls
- Scientific mode with sin, cos, tan, square root, square, cube, exponent, log, ln, pi, e, and parenthesis
- DEG and RAD angle modes
- Calculator memory
- Calculation history stored locally on the device
- Light and dark themes
- Optional haptic feedback
- Optional sound effects
- Copy result to clipboard
- Keyboard support on desktop
- Responsive layout designed for iPhone, Android, tablet, and desktop
- Settings modal with a working Force Update button
- No external libraries or API keys required

## Run

Open `index.html` in a browser, or deploy the repository with GitHub Pages.

## Files

- `index.html` — app structure and controls
- `style.css` — responsive UI, themes, and mobile layout
- `app.js` — calculator engine, scientific functions, memory, history, settings, and interactions
